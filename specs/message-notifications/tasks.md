# 消息通知功能实施计划

- [x] 1. 建立消息领域模型与公共规则
  - 定义通知类型、公告状态、投递状态和安全跳转目标枚举
  - 实现确定性消息 ID、文本截断、日期格式和提醒窗口公共函数
  - 为历史用户兼容 `reviewVersion`、`maintenanceVersion` 等缺省字段
  - _需求：R1、R2、R3、R4、R5、R10_

- [x] 2. 扩展审核结果通知
  - 将管理员审核更新改为事务处理
  - 审核通过和拒绝时创建幂等站内消息
  - 拒绝消息包含审核原因，重复审核不产生重复消息
  - _需求：R1、R10_

- [x] 3. 扩展预约成功与取消通知
  - 普通用户预约成功后生成预约确认消息
  - 管理员代预约后向目标用户生成代预约消息
  - 用户取消和管理员取消后生成取消消息，管理员取消包含原因
  - 保证业务状态与站内消息的事务一致性
  - _需求：R2、R3、R10_

- [x] 4. 实现设备维护通知
  - 设备切换为 `MAINTENANCE` 时递增维护版本
  - 查询该设备未来有效预约用户并生成幂等维护消息
  - 保留禁用时段冲突校验，不自动取消预约
  - 管理员因维护取消预约时复用带原因的取消通知
  - _需求：R5、R10_

- [x] 5. 新增 `notification` Event 云函数基础接口
  - 实现当前用户识别和管理员权限校验
  - 实现未读汇总、分页列表、单条已读、全部已读
  - 合并定向消息、有效公告及公告已读状态
  - 实现订阅模板列表和授权结果快照接口
  - _需求：R7、R8、R10_

- [x] 6. 实现公告管理接口
  - 实现管理员公告列表、发布和停用操作
  - 校验标题、正文、开始时间、结束时间和微信推送选项
  - 使用公告文档与用户阅读记录避免站内公告批量复制
  - _需求：R6、R7、R10_

- [x] 7. 实现通知配置与微信订阅投递
  - 新增 `settings/notification` 默认配置和服务端校验
  - 实现管理员配置读取与保存，提醒提前量仅允许 15/30 分钟
  - 使用服务端模板字段映射构造订阅消息
  - 记录 `SENT`、`FAILED`、`SKIPPED` 投递状态和脱敏结果
  - 确定性失败不重试，临时失败最多重试一次
  - _需求：R8、R9、R10_

- [x] 8. 实现预约开始定时提醒
  - 在 `notification` 云函数中实现 `BOOKED` 预约提醒扫描
  - 支持提前 15/30 分钟并使用重叠扫描窗口
  - 排除已取消、已签到和已结束预约
  - 通过确定性消息 ID 防止定时任务重复提醒
  - 配置每 5 分钟执行的 timer 触发器
  - _需求：R4、R9、R10_

- [x] 9. 实现普通用户消息中心
  - 新增 `pages/notifications/index` 页面及路由
  - 实现时间轨道列表、未读状态、分页和空状态
  - 实现消息展开、单条已读、全部已读和安全业务跳转
  - 实现用户主动触发的“开启微信提醒”入口
  - _需求：R7、R8_

- [x] 10. 在“我的”页面增加消息入口
  - 增加最近消息摘要、未读数字徽标和进入操作
  - 页面显示时刷新未读数量
  - 未读为 0 时隐藏数字徽标
  - _需求：R7_

- [x] 11. 实现管理员公告与通知设置页面
  - 新增 `pages/admin/announcements` 页面及公告发布抽屉
  - 实现公告状态汇总、筛选、详情和停用确认
  - 新增 `pages/admin/notification-settings` 页面
  - 实现提醒时间、模板状态、模板 ID 和字段映射配置
  - 在管理首页增加“消息与公告”入口
  - _需求：R6、R9_

- [x] 12. 接入业务场景订阅授权
