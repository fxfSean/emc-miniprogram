# 设备独立签到位置需求

## 目标

将全局单一实验室签到点调整为每台设备独立的签到位置。管理员在设备新增或编辑弹层中通过微信地图选点，不需要到设备现场采集当前位置。

## 用户故事与验收标准

### R1 管理员地图选点

- 当管理员编辑设备时，系统应允许通过微信地图搜索或选择地点。
- 当地图选点成功时，系统应保存地点名称、地址及 GCJ-02 经纬度，并展示地图和签到范围预览。
- 当管理员取消地图选点时，系统应保留原设备位置。
- 当设备状态为可预约时，系统应要求设备具有有效坐标和 20–2000 米签到半径。

### R2 设备独立围栏

- 当用户签到时，系统应根据预约对应设备读取签到坐标和半径。
- 当用户超出该设备签到范围时，系统应拒绝签到并返回该设备的允许范围。
- 当设备没有独立签到位置时，系统应在迁移期回退到原全局签到位置。
- 当设备位置在签到过程中发生变化时，系统应要求用户重新签到。

### R3 安全与隐私

- 普通用户不得获得设备签到点的精确经纬度。
- 设备位置配置只能由通过审核的管理员经云函数修改。
- 用户只能提交自身实时位置，目标坐标、距离和准入结果必须由云函数确定。
- 签到记录应保存实际使用的目标位置快照和计算距离，用于后续审计。

### R4 位置展示与兼容

- 设备详情、预约页面和我的预约应展示设备的可读位置。
- 当旧设备尚未配置独立位置时，管理员编辑页应加载旧全局位置作为迁移默认值。
- 新版预约规则页应只维护全局签到时间与定位精度，设备坐标和半径应在设备管理中维护。

## 非目标

- 不新增实验室地点集合或独立实验室管理页面。
- 不保证 GPS 能区分同一建筑内的不同房间。
- 本期不接入二维码、NFC、蓝牙或 Wi-Fi 校验。
